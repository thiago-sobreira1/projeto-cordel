# Projeto Cordel

Página web dedicada à obra de cordel de Milton Duarte, desenvolvida como projeto prático de estudo em HTML e CSS.

## 🖥️ Sobre o projeto

Este projeto une tecnologia e cultura popular brasileira, apresentando o cordel de Milton Duarte em formato de página web, com foco em:

- Estruturação de conteúdo textual e visual
- Estilização com CSS3
- Boas práticas de layout

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 🚀 Como executar

1. Clone o repositório:
```bash
git clone https://github.com/thiago-sobreira1/projeto-cordel.git
```
2. Abra o arquivo `index.html` no navegador.

## 📚 Aprendizados

Este projeto foi uma oportunidade de praticar HTML e CSS aplicados a um conteúdo cultural, trabalhando tipografia, organização de texto longo e estilização de página.
